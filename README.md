# Directorio Corporativo

Directorio interno con filtros, busqueda y modal detallado por colaborador.

## Funciones

- Busqueda por nombre, rol, habilidad o manager.
- Filtros por area, sede y turno.
- Tarjetas de colaboradores con avatares consistentes.
- Perfil detallado en modal y favoritos persistidos localmente.

## Uso

```bash
npm install
npm run dev
```

Genera build con `npm run build`.
## Modos de uso

- Desarrollo: `npm install && npm run dev`
- Archivo estatico: ejecuta `npm run build` y abre `index.html` en la raiz del proyecto.
